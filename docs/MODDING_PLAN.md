# Recon scope

This is an Android runtime feasibility project, not an installed-PC mod. The selected reference is OldUnreal UT v469e Linux ARM64, native ELF; local ownership/install path, saves, anti-cheat and online behavior have not been investigated. See UPSTREAM for official installation notes and FEASIBILITY for the selected gated route. No existing install or saves were modified; no online test is authorized by this diagnostic step.
